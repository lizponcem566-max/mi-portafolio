La Canasta de Mamá — Tienda Online

Plataforma de comercio electrónico dinámica desarrollada para la venta de arreglos y regalos personalizados. Conectada a una base de datos relacional para la gestión completa de catálogo, usuarios y procesamiento de pedidos.

PHP MySQL XAMPP JavaScript HTML5 / CSS3
Detalles del Proyecto
Tipo de Proyecto E-Commerce / Full Stack
Sector Regalos & Retail
Rol Desarrolladora Web & BD
Tecnologías PHP, MySQL, XAMPP, JavaScript, CSS3

El Desafío

Crear una tienda en línea funcional e intuitiva que permitiera a los clientes explorar el catálogo de productos por categorías, autenticarse, agregar artículos a un carrito de compras interactivo y enviar solicitudes de pedidos.

Funcionalidades Desarrolladas

  • Módulo de Autenticación: Sistema de inicio de sesión y registro de clientes conectado a MySQL.
  • Catálogo Dinámico: Vista detallada de productos cargados desde la base de datos.
  • Carrito de Compras: Lógica frontend/backend para sumar ítems, calcular subtotales y gastos de envío.
  • Formulario de Contacto y Pedido: Sección dedicada a atención personalizada y recepción de dudas.
